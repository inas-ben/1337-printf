# ft_printf

## Description

The **ft_printf** project is part of the 42 School curriculum. The goal of this project is to recreate the behavior of the standard C library function `printf()`.

The project consists of developing a custom function called `ft_printf()` that handles formatted output using variadic arguments.

Through this project, I learned how variadic functions work in C, how to parse format strings, how to handle different data types, and how to manage output using the `write()` function.

The library generated by this project is called `libftprintf.a`.

### Supported Conversions

The mandatory part supports the following conversions:

| Conversion | Description |
|---|---|
| `%c` | Prints a single character. |
| `%s` | Prints a string. |
| `%p` | Prints a pointer address in hexadecimal format. |
| `%d` | Prints a signed decimal integer. |
| `%i` | Prints an integer in base 10. |
| `%u` | Prints an unsigned decimal integer. |
| `%x` | Prints an unsigned hexadecimal number in lowercase. |
| `%X` | Prints an unsigned hexadecimal number in uppercase. |
| `%%` | Prints a percent sign. |

## Instructions

### Compilation

To compile the library, run:

```bash
make
```

This generates the static library:

```text
libftprintf.a
```

The library is created at the root of the repository.

### Makefile Rules

The Makefile provides the following rules:

| Command | Description |
|---|---|
| `make` | Compiles the project and creates `libftprintf.a`. |
| `make all` | Compiles the library. |
| `make clean` | Removes object files. |
| `make fclean` | Removes object files and the library. |
| `make re` | Recompiles the project from scratch. |

### Usage

To use `ft_printf()` in another C project:

1. Include the header file:

```c
#include "ft_printf.h"
```

2. Compile your program with the library:

```bash
cc -Wall -Wextra -Werror main.c libftprintf.a -o test
```

3. Call `ft_printf()` in your code:

```c
#include "ft_printf.h"

int main(void)
{
	ft_printf("Hello, %s!\n", "42");
	ft_printf("Number: %d\n", 42);
	ft_printf("Hexadecimal: %x\n", 255);
	ft_printf("Pointer: %p\n", (void *)main);
	return (0);
}
```

## Algorithm and Data Structure

### Algorithm

The implementation of `ft_printf()` is based on a format-string parsing algorithm.

The function processes the format string character by character:

1. Initialize a variadic argument list using `va_start()`.
2. Iterate through the format string.
3. If the current character is not `%`, print it directly using `write()`.
4. If a `%` is encountered, inspect the following character to identify the conversion specifier.
5. Retrieve the corresponding argument using `va_arg()`.
6. Call the appropriate conversion function to print the argument.
7. Count the number of characters written.
8. End the variadic argument list using `va_end()`.
9. Return the total number of characters printed.

### Data Structure

The main data structure used in this project is `va_list`.

It allows the function to access a variable number of arguments passed to `ft_printf()`.

The implementation also uses:

- A format string (`const char *`) to identify the requested conversions.
- Integer variables to track the current position in the format string.
- An integer counter to keep track of the number of characters printed.
- Temporary variables to store converted values.

No complex data structures are needed because the format string can be processed sequentially.

### Algorithm and Data Structure Justification

A sequential parsing algorithm is appropriate because the format string must be interpreted from left to right.

Each conversion is handled independently through dedicated helper functions. This makes the implementation modular, easier to understand, maintain, and test.

Using `va_list` is necessary because `ft_printf()` accepts a variable number of arguments, allowing it to process different data types depending on the conversion specifier.
